# Qt Bridge — Python

Qt Bridge is a framework that makes Python-QML integration effortless.
It automatically exposes Python classes, properties, signals, and methods to QML
with minimal boilerplate — no manual ``@Slot``, ``@Property``, or meta-object
plumbing required.
